# Discord.py Components v2 (Cv2)

Welcome to **Discord.py Components v2 (Cv2)** – an updated component system designed for a cleaner, more powerful, and modular way to build Discord bot interfaces.

---

## ✨ What's New in Cv2?

- **Modern Layout System** → Replace `View` and `add_item` with structured `LayoutView` and `Container`
- **New UI Elements** → `TextDisplay`, `Separator`, `MediaGallery`, `File`
- **Cleaner Syntax** → No more repetitive `view.add_item()`
- **Better Organization** → Components grouped into `ActionRow` and `Container`
- **More Visuals** → Built-in support for media carousels, file attachments, and inline text

---

## 🚀 What is Cv2?

**Cv2** is the new component/layout system in discord.py for building modern, modular, and powerful Discord bot UIs.

**Key Features:**

- Structured layouts with `LayoutView`, `Container`, `ActionRow`
- New UI elements: `TextDisplay`, `Separator`, `MediaGallery`, `File`
- Cleaner, more readable syntax
- No more `add_item()` everywhere
